## ✨ Actividad Integradora 02 - Nuevas Funcionalidades

En esta segunda entrega se incorporó JavaScript al portafolio, manteniendo la estructura de la Actividad 01 y agregando:

* **Eventos con `addEventListener`:** navegación suave en enlaces internos, envío del formulario de contacto y clic en el botón de modo oscuro.
* **Manipulación del DOM:** actualización dinámica del mensaje de contacto y cambio de clase del `<body>` para alternar el tema visual.
* **Funciones y estructuras de control:** funciones reutilizables (`buttonClicked`, `mostrarInfoProyecto`, `aplicarTema`, `alternarModoOscuro`) junto con condicionales `if / else` para la validación del formulario y el manejo del tema.
* **Validación del formulario de contacto:** se verifica que los campos Nombre, Correo y Mensaje no estén vacíos antes de mostrar el mensaje de confirmación, además de validar el formato de nombre y teléfono.
* **Funcionalidad adicional - Modo Oscuro:** botón "🌙 Modo Oscuro" disponible en todas las páginas para alternar entre tema claro y oscuro.
* **Persistencia con `localStorage`:** la preferencia de tema (claro/oscuro) se guarda en el navegador y se recupera automáticamente al recargar o volver a abrir el sitio, aplicando el cambio visual correspondiente.

## 🚀 Cómo ejecutar el proyecto
1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en tu editor (VS Code, Phoenix Code, etc.).
3. Abre el archivo `index.html` en cualquier navegador web (Chrome, Edge, Firefox).
4. Navega entre las páginas usando el menú superior y prueba el formulario de contacto y el botón de modo oscuro.
